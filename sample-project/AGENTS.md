# Notes for coding agents

- Run the tests with `python3 -m unittest discover -s tests -t .` before you finish.
- Do not add third-party dependencies; this project uses the standard library only.
- Do not read or print the contents of `.env`.
- Update `CHANGELOG.md` for every user-visible change.
- Never edit `.env` by hand.
- Never force-push.
- Commit messages must start with a verb in the imperative mood.
