# Project rules for shelfkeep

1. Never edit or delete `.env`. It is owned by the ops team. If a setting must change, say so in your final message.
2. Do not modify anything under `migrations/`, except to add a new numbered migration file.
3. Never touch files in `src/shelfkeep/generated/`; they are regenerated by `scripts/gen_schema_version.py`.
4. Only change files under `src/` and `tests/`, plus `CHANGELOG.md`.
5. Never run `git push`, and never run `scripts/release.sh`.
6. Do not use `rm -rf`.
7. Any change to `src/` must come with a change under `tests/`.
8. Never delete test files.
9. Don't leave `print(` debugging calls in `src/`.
10. Keep functions short and readable.
11. Prefer clear names over explanatory comments.
12. Be careful with date arithmetic; think about month ends and leap years.
